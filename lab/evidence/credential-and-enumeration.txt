# Credential attacks and information disclosure
date: 2026-10-19T08:53:20Z

## 1. Username enumeration via login errors (main lab)
existing admin + wrong password: password you entered for the username 
nonexistent user + wrong password: not registered on this site. If you are unsure of your username, try your email address instead.

## 2. Username enumeration via lost-password form (main lab)
existing admin: no 'no account' error; reset flow started (local mailer cannot send)
nonexistent user: There is no account with that username or email address.

## 3. Public username exposure
GET /?author=1 -> 200
GET /author/admin/ -> 200
REST /wp/v2/users -> [(1, 'admin')]

## 4. Rate limiting (clone, 12 consecutive failures)
http/errors per attempt: 200/3 200/3 200/3 200/3 200/3 200/3 200/3 200/3 200/3 200/3 200/3 200/3
valid login after 12 failures: <title>Dashboard &lsaquo; WP Admin RCE Lab &#8212; WordPress

## 5. Weak admin password + XML-RPC (clone, password deliberately set to Lab-Demo-Weak-1)
candidate 1 (Password123!)      -> fail
candidate 2 (letmein)           -> fail
candidate 3 (Lab-Demo-Weak-1)   -> SUCCESS (wp.getUsersBlogs returned blog data)

## 6. system.multicall behaviour (main lab)
c-c (two valid calls)            -> 0 faults, 2 successes
c-w (valid then invalid)         -> 1 fault, 1 success
w-c (invalid then valid)         -> 2 faults, 0 successes
note: a failed attempt poisons later calls in the same batch, so multicall
      does not amplify guessing on this WordPress version.
